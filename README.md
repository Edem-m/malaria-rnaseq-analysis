# Transcriptomics Analysis of Severe Malaria Patients

## Overview
This project explores gene expression patterns in transcriptomics data from patients with severe malaria. The goal was to use computational analysis to better understand how gene expression differs across patients and how these patterns may relate to disease severity and immune response.

This project was completed as part of the **JAX Biomedical Data Science in Context (BDSiC)** program, where I worked through the analysis using pair programming and guidance from JAX instructors and mentors.

---

## Research Questions
- How does gene expression differ across severe malaria patient samples?
- Are there patterns in transcriptomics data that may help explain differences in disease severity or immune response?

Rather than focusing on a single gene, this project approaches the data at a broader level to understand overall expression trends.

---

## Data
- Transcriptomics (RNA-seq) data from severe malaria patient samples  
- Data was provided for educational and training purposes through the BDSiC program  

> **Note:** Raw data files are not included in this repository due to size and access restrictions.

---

## Methods
- Data exploration and basic preprocessing  
- Comparison of gene expression patterns across patient groups  
- Visualization of expression trends using plots and summary statistics  
- Pair programming and group discussion to interpret results in biological context  

Analysis was performed using **Python and R**, with an emphasis on understanding what the data represents rather than applying methods mechanically.

---

## What I Learned
Through this project, I learned:
- How to approach transcriptomics data step by step  
- How biological context should guide analytical choices  
- The importance of asking *why* patterns appear, not just identifying that they do  
- How collaboration and discussion improve the interpretation of complex biological data  

This experience sparked my interest in transcriptomics and reinforced my desire to continue working with gene expression data in future research.
